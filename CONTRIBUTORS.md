# Contributors

This file recognizes people who have contributed to Athena. It is
maintained by hand and updated via pull request — GitHub's own
[contributors graph](../../graphs/contributors) is the automatically
generated, always-current source if this file ever drifts out of date.

## How to add yourself

Contributions of any kind are welcome here, not only code — documentation,
subsystem specification work, curated data (guidelines, access pathways),
issue triage, and review all count.

Once you've made a merged contribution, add yourself to this file in the
same PR or a follow-up one:

```markdown
- [**your-github-handle**](https://github.com/your-github-handle) — one-line description of your contribution area (optional)
```

Please use only your public GitHub handle and, optionally, a real name
you're comfortable publishing — do not add anyone else's name without
their permission.
