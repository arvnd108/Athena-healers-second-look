# Changelog

All notable changes to this project should be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project intends to adopt [Semantic Versioning](https://semver.org/)
once a first tagged release is cut.

## [Unreleased]

### Added
- Open-source governance files: `POLICY.md`, `CONTRIBUTORS.md`,
  `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`,
  `GOVERNANCE.md`, `SUPPORT.md`, issue/PR templates.
- Nineteen tracked subsystem roadmap issues (A–S), each with interfaces,
  deliverables, and caveats, labeled by status/priority/area.

### Notes
- `pyproject.toml` currently declares version `1.0.0`, but no tagged
  GitHub release or formal versioning process exists yet. Once one does,
  entries above `[Unreleased]` should follow `## [x.y.z] - YYYY-MM-DD`
  and this note should be removed.
- Known, currently-open issues with the existing implementation are
  tracked in `ISSUES.md`, not here — this file is for tracking releases
  going forward, not restating current limitations.
